# La Morada — demo de presentación

Esta carpeta contiene únicamente la web de muestra y datos públicos del proyecto. No incluye credenciales, base de datos privada, solicitudes de clientes ni el panel de administración.

## Publicar en GitHub Pages

1. Crea un repositorio y sube el CONTENIDO de esta carpeta; index.html debe quedar en la raíz.
2. En Settings → Pages selecciona Deploy from a branch, la rama main y /(root).
3. Guarda y abre la dirección que indique GitHub.

Para probarla en Windows, haz doble clic en ABRIR-DEMO.cmd y deja abierta la ventana mientras la usas. Requiere Node.js; en este equipo también detecta el incluido con Codex. No abras index.html directamente para usar el 3D. En GitHub Pages se abre desde su enlace web.

## Alcance

El plano, los renders, el video y la navegación son demostrativos. Los formularios están desactivados y no registran solicitudes. La disponibilidad y precios son una fotografía del catálogo a la fecha del manifiesto; deben confirmarse con el equipo. La plataforma completa mantiene su panel y base de datos en un servidor.
